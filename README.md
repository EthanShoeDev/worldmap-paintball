# worldmap-paintball

**[Play it here →](https://worldmap-paintball-web-live-ethan-c7vlagz77zbarwhz.ethanshumate.workers.dev)**

A multiplayer paintball game you play in a real place. Search for an address
anywhere in the 50 US states or DC, such as your street, your school or a
downtown block. The game builds an arena from real map data: buildings at their
real heights, roads, parks, water, trees and the actual lie of the land. Then
you and your friends shoot it out in it.

- **Play with friends:** open a lobby and share its six-character code. Match
  traffic goes between browsers over WebRTC. The server only runs the lobby and
  passes the connection setup between players.
- **Or practice solo** against bots that find their way around the arena.
- **Loadout:** three markers (assault, sniper and shotgun). Power-up pads give a
  jetpack, a paintball launcher, x-ray vision or extra speed.
- **Arenas come from open data:** buildings and roads from OpenStreetMap via
  OpenFreeMap, Microsoft's building footprints where OSM has no buildings,
  and elevation from AWS terrain tiles. Each arena is baked once and cached,
  so everyone in a lobby gets the same one.

It runs on Cloudflare: a single Worker serves the site and the API, with
Durable Objects for lobbies and arena baking, and R2 for cached arenas and
building footprints.

## Development

```sh
bun install
bun run --cwd apps/api dev        # Bun API server, port 3000 (lobby WebSockets)
bun run --cwd apps/web dev        # Vite: the site and the rest of /api
bun run test                      # all tests (never `bun test`)
bunx turbo run lint:check         # lint + typecheck, no writes
bunx turbo run lint               # apply lint and format fixes
bun run shoemaker:sync            # update generated tooling
```

`bun run infra:deploy` deploys to Cloudflare. It needs `ALCHEMY_PROFILE=personal`
in `.env.local`.

Stack: bun workspaces with every version in the root catalog, Effect v4,
TypeScript 7, turbo, oxlint and oxfmt, vitest with `@effect/vitest`, varlock for
env (`.env.schema`), and a Nix dev shell (`direnv allow` or `nix develop`).
Repo tooling is generated by [shoemaker](https://github.com/EthanShoeDev/shoemaker)
from `shoemaker.config.ts`.
